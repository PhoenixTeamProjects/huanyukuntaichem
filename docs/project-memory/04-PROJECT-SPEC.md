# 04 - Project Spec

## Goal

Build a multilingual industrial B2B website focused exclusively on fuel additives, lubricant additives, and lubricant additive packages.

## Current Version Target

Version 0.2 turns the initial skeleton into a company-specific website based on the verified chemical-division business master document while preserving the existing header menu.

## Scope

- Home
- Products
- Product category
- Product detail
- News
- News detail
- Applications
- Service
- About
- Contact
- Inquiry submission route

## Content Ownership

Directus is the source of truth for products, categories, news, applications, pages, SEO, image alt text, and inquiries.

Verified code fallback content may support development before CMS migration, but it must remain clearly identified as fallback and must not contain invented technical or commercial data.
